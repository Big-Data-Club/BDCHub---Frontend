# Knowledge Farm visual source

Sprites copied from the user-provided local source.
Its README describes these as original project sprites generated by
`tools/generate_sprites.py`. No third-party asset pack was added.

`FarmWorld.Pixel` and selected-plot interaction adapt the `Pix` component and
entity-selection idea in `PlayerView.tsx`. The server timer / rest / re-care
loop follows `backend/internal/domain/economy.go`. The accessible React grid
uses the existing frontend stack without adding Phaser or real-farm workflows.
